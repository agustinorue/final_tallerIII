# HURDAT2 — Análisis espacial interactivo

Informe web interactivo sobre la distribución espacial y el ciclo de vida de los ciclones tropicales registrados en HURDAT2.

## Contenido

- Mapa mundial real con capas de OpenStreetMap y Esri World Imagery.
- Puntos de génesis y máximos de intensidad.
- Identificación de eventos de intensificación rápida.
- Filtros por cuenca, período y mes de génesis.
- Estacionalidad, trayectorias, entradas a tierra y casos extremos.
- Informe metodológico y advertencias para interpretar los resultados.

Abrí `index.html` para explorar el informe. El mapa base requiere conexión a Internet.

## Datos y metodología

Fuente: NOAA/National Hurricane Center, HURDAT2 (Atlántico 1851–2025 y Pacífico NE/NC 1949–2025). Las distancias se estiman mediante haversine. Se considera intensificación rápida un aumento de al menos 30 kt en aproximadamente 24 horas.
